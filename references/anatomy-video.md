# Anatomy 视频场景

把 Anatomy 的等距实体装置作为视频的解释语言，沿用本技能的脚本、连续配音、字幕和交付流程。上游为 https://github.com/wheresryan22/anatomy（MIT）。读取已安装 Anatomy 的 `SKILL.md`、`references/craft.md` 和最接近的示例；不要仅凭名称模拟一个普通卡片动画。

## 两种使用方式

- **局部插入**：保留其他段落和原音轨；为指定语义区间生成同尺寸、同 fps 的无声片段，用现有合成流程替换或叠加画面，声音只混入一次。片段使用全局时间取样，保持字幕和动作时间一致。
- **全片默认**：使用贯穿全片的装置或相关物体，通过不同构图、局部特写和状态改变组织章节。无需每幕造一台新机器；真实效果主张仍需实际证据。按内容决定是否组合真实界面。

记录 `visualMode: anatomy`、`scope: insert | full` 和时间区间在分镜中；这些是制作记录，不是现有 `motion.json` 的新增字段。未指定范围时结合上下文选择并说明，不改变项目的永久默认。

## 从概念到场景

先写一句“什么移动、移动意味着什么”，列出概念到零件的映射与比喻边界。例如项目记忆库可对应档案柜，检索对应取出相关档案；不要把抽屉容量或机械动作冒充软件的真实结构、速度或效果。画面标注“原理示意”。

使用上游几何 kit 构建有底座、支撑、轨道、把手、凹槽等合理零件的实体。继承其体积、遮挡、精细结构和运动因果；视频的品牌色、中文标题、字幕、安全区和叙事优先，不强制套用网页交互提示或单色卡片外框。先测试手机尺寸下能否看懂，再增加微小装饰。

## 视觉叙事与漫画分镜

Anatomy 提供装置与几何表达，视频导演层需要另行设计。导入 kit、渲染成功、同一装置换标题或抽屉位移，均不足以证明全片的分镜与动效已经完成。全片应按论述展示不同景别和可见变化，保持同一对象的连续性；不要让一个固定全景承担所有内容。

当用户要求“漫画分镜、气泡对话、科技感”时，把这些写入当次分镜验收项：

- 对话以有明确说话对象和阅读顺序的气泡出现，按口播语义安排入场；说明文字与对话区分。气泡中的模拟对话标为示意，不冒充产品真实回复。
- 按事件拆成单格、上下格或双格，用镜头切换、局部放大和物体动作推进叙事；布局切换要实际渲染出来。
- 用明确的转场连接相关镜头，例如分格展开、整页滑动或遮罩斜切。转场通常约0.3–0.6秒，不能只给标题淡入就称全片有转场；字幕和声音保持连续。
- 科技感通过设备结构、信号流动、扫描状态、清晰的冷暖对比表达，并检查手机可读性；单独换成蓝色背景不算完成。
- 先渲染包含对话、动作和至少一次完整转场的连续样片，检查转场中间帧与停稳帧；通过这些具体项后再扩展全片。区分静态帧检查、连续状态检查和主观带声播放。

这是一种按用户要求选择的表现方式，不强加给所有 Anatomy 视频。保留无需气泡的技术插图和克制的等距解说模式。

`assets/anatomy-video/comic-svg.mjs` 提供 `createComicSvg({fontFamily, palette})`，返回 `panel`、`bubble`、`txt`、`r`、`line` 及缓动函数。`bubble(x, y, width, lines, tailSide, fill, fontSize)` 按行数计算高度并绘制尾巴；仍需根据说话对象安排位置，并检查气泡、主体、字幕及来源标注的间距。组件本身不替代分镜设计。

## 确定性 SVG 路径

`assets/anatomy-video/` 提供 **纯 SVG** 逐帧渲染器，可用于局部片段和整片。它不支持浏览器 CSS 动画、WebGL 或 Three.js；这些需另写按时间 seek 的浏览器适配并验证，不能声称已支持。

1. 把 `assets/anatomy-video/` 复制到任务目录，运行 `npm ci`。把 Anatomy 的 `kit/` 和 `LICENSE` 复制到任务内 `vendor/anatomy/`，记录上游版本或 commit，保留 MIT 版权。
2. 编写任务 `scene.mjs`，导出 `width`、`height`、`fps`、`duration`、`fontFiles`、`renderFrame(seconds)`。后者返回完整 SVG 字符串；几何应直接调用 Anatomy kit。声音和字体路径相对场景文件解析。SVG 样式用可解析的显式颜色，不能假定栅格器支持 CSS 变量。
3. 动画与字幕只依赖输入时间。预计算静态几何；移动物体按世界坐标转换，遮挡顺序随位置变化时重新排序。不要使用实时时钟、无种子随机或上次调用的动画状态。
4. `node render.mjs scene.mjs stills --times=0,2,5` 输出 PNG；`FFMPEG_BIN=/path/to/ffmpeg node render.mjs scene.mjs clip.mp4 --start=5 --end=10` 生成指定区间无声片段；整片省略 start/end。`--audio=path.wav` 只接受完整音轨并按相同起止裁取，不补静音。
5. 原片局部替换必须检查剪辑接点；全片检查字幕覆盖、帧时长与连续声音。该渲染器导出视频，不生成交互 HTML；若另行交付 HTML，遵循本技能原有 HTML 流程。

`node check-scene.mjs scene.mjs` 检查有限几何和乱序取样的一致性。`examples/validation.mjs` 提供串行／并行队列比较、缓存匹配释放闸门两个无声工程样例；设置 `ANATOMY_KIT` 为实际 `kit/iso-kit.mjs` 路径后，可用相同命令渲染。它们只覆盖渲染与时间驱动接口，不是可直接发布的视频模板。

## 检查与边界

先实渲代表段落，查看静态构图及连续运动帧后扩展。检查输入同一时间重复及乱序渲染得到相同输出；局部片段首帧须与整片同时间一致。不同主题使用不同解释结构做短测试，明确自动检查与视觉评审范围。

沿用 Anatomy 中与所用几何对应的检查：使用管道、圆曲面或复杂空间交叠时运行上游几何审计；不能以自行写的通过字段代替。纯 SVG 视频适配不自动证明上游浏览器交互、WebGL、3D 或所有几何审计已通过。记录未执行项。实际成片要完整解码，并检查运动、字幕、音画语义；复用旧音轨时说明未重新合成及其原有验收边界。

# Editorial v4：先设计画面，再让画面运动

本路线用于用户要求精致知识解说、杂志/报告/纸感参考风格，或要求可复用的水波纹、扩散、翻转。不是所有主题强制套用的唯一风格；已有录屏/共享 UI 路线仍保留。不能仅填写“精美”或增加转场数量。

## 可执行制作顺序

1. **证据和论点**：每镜一句观众收益/因果，不以“动画升级、风格验证”作正式视频标题。当前官方材料支持到哪里就讲到哪里。示意数据必须标注；免费、包含、无限等结论保留适用条件。
2. **视觉提案**：以 `assets/acceptance/visual-plan.template.json` 为结构，写清主体、布局理由、材质、状态变化、实际 renderer/function。形态标签不是渲染器的 JSON 配置。先读 `assets/editorial-motion/README.md` 调用真正支持的布局。
3. **关键帧先行**：渲染每镜最关键状态（不只开场），检查大中小信息层级、主次、边缘留白、字形碰撞、图解与论点对应。物体/纸张/阴影必须服务内容；不给每页加相同圆角卡片。先改静态设计，再加运动。
4. **有理由地选转场**：按 [transitions.md](transitions.md) 把波源、扩散中心、翻转对象绑到内容。三种能力可复用，不要求每片三种凑齐。正常阅读停留不是失败；不要用不断动来伪装质量。
5. **实际样片**：渲染包含最难状态变化、一个场间衔接及真实字幕安全区的短样片。在原速检查前/中/后与实际连播；先修复，再扩展。无声样片显式标注，不能算声音验收。
6. **最终时间线复验**：实际配音加入后重新检查阅读时长、遮挡、结尾和转场。门禁用 schema 2/profile editorial-v4；运行 `check_acceptance.py record.json --require-profile editorial-v4`，不得用旧 schema 1 代替。每次改片后旧 SHA 证据失效。

## 内容→信息形态，不是模板轮换

| 解释任务 | 建议画面与动作 | 拒绝的捷径 |
|---|---|---|
| 一个核心区别 | 编辑式大标题+单一具体物件，次要说明退后 | 同时两处等重巨字争焦点 |
| 账单/权限/条件 | 收据或账本，行项目与限定词一起出现 | 单独巨大“免费”掩盖条件 |
| 持久记忆/筛选 | 笔记本、索引与抽取页；选中信息被送入目标 | 随便一排蓝卡片横移 |
| 因果/工作流 | 明确输入→操作→输出；线条绕开文字 | 箭头有运动但不表达关系 |
| 数量/趋势 | 有来源图表，清楚尺度；示例标示意 | 无证据百分比和装饰图表 |
| 操作/界面 | 核实截图或真实操作，镜头聚焦具体控件 | 自画界面冒充产品实测 |

## 视觉验收不是评分彩票

每镜记录 reviewer 与具体观察，不填空泛“很美”。五项逐一通过：hierarchy、composition、material_consistency、legibility、content_fit。检查真实尺寸和手机缩小观看：标题不撞物体轮廓、不穿过字；主焦点明确；阴影/透视一致；主体可读；图解确实承载当前结论。评审失败必须改稿/改图；两轮仍不满足只能标未通过草稿，不能自称达到参考。

门禁能验证证据完整、文件哈希、检查状态，不能证明评审诚实、事实准确或美学优秀。独立审阅实际关键帧+播放优先，不以单测通过代替审美。

参考仅提炼构图/材质/信息形态，不复制参考成片、截图、音乐或独特插画。用户无需事先提供所有素材；先用有授权的官方素材和原创图解补齐，缺少只能由用户授权的原素材时才明确说明。
